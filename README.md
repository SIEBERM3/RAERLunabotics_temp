# RAERLunabotics_temp
Temporary repo for RAER Lunabotics Club

This will serve as the inital codebase for the 2026-2027 Lunabotics Rover (which will be transferred to a main git at some point)
Everything is built from the ground up so be prepared for some bare bones code

Goals: Communicate with sensors (LiDAR and Camera), identify obstacles, determine path, and communciate path into motor commands


To start working: 
--> click the green code button in the top right of the workspace
--> copy the clone https link
--> go into terminal (git needs to be installed) and navigate to where you want the workspace to be stored - cd /folder/
--> Finally, type "git clone -your https link-" 
Open it up on VSC and code away


To push modifications:
--> Go to Source Control in VSC
--> Add a message of what you did and then commit your changes!
